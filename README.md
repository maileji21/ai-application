# AI 穷游攻略生成器

输入目标城市，自动采集高德 POI 景点数据，调用大模型分批生成门票参考价与穷游攻略，命令行与 Flask 网页两种使用方式，全流程带质量统计。

技术栈：Python / Flask / 高德开放平台 API / 智谱 GLM-4-Flash

## 核心指标（5 城实测）

| 指标 | 数值 |
|---|---|
| 覆盖城市 | 杭州 / 重庆 / 北京 / 成都 / 西安 |
| 累计采集景点 | 192 个（6 类景点，名称前缀去重） |
| LLM 批次调用 | 40 批，成功率 100%，0 次重试 |
| 攻略覆盖率 | 100%（192/192） |
| token 消耗 | 输入 5,105 / 输出 20,611 |
| 模型成本 | 0 元（GLM-4-Flash 免费；初版 Qwen2.5-7B 同 token 量估算约 ¥0.008/城市） |

## 设计要点

- **分批调用**：每批 5 个景点。小模型单次输出长度有限，一批景点太多会导致攻略被截断成半句 JSON，解析直接失败
- **三级容错**：JSON 解析失败自动重试（最多 2 次）→ 字段校验（一批中有效条目 ≥60% 才算成功）→ 仍不合格整批降级跳过，字段留空但不中断整体流程
- **输出稳定性**：max_tokens 显式给足防止中途截断；temperature 压到 0.3 降低随机性；prompt 约束只输出固定 JSON 结构，解析前剥离代码围栏
- **质量报告**：每城市输出批次成功率、攻略覆盖率、token 用量、成本，落盘 `{城市}_run_stats.json`
- **成本优化**：初版使用硅基流动 Qwen2.5-7B（付费），实测 token 用量后迁移至智谱 GLM-4-Flash（免费），功能不变成本降为 0

## 怎么跑

```bash
pip install requests flask
```

设置环境变量（PowerShell）：

```powershell
setx gaode_API "你的高德开放平台key"
setx GLM_API  "你的智谱开放平台key"
```

命令行版（输入城市与偏好，结果保存为 csv）：

```bash
python 旅游攻略.py
```

网页版（表单输入 → 采集 → AI 分析 → 结果页渲染）：

```bash
python 旅游攻略_网页版.py
```

## 已知限制

- 高德 POI 每类景点只取第一页 8 条，是抽样而非全量
- 攻略内容由免费模型生成，门票价格为参考价，出行前请以官方信息为准
- Flask 为同步处理，单次请求约 1-2 分钟，适合本地使用；正式上线需改造为异步任务队列
- LLM 输出格式依赖 prompt 约束 + 围栏剥离，未做 JSON Schema 强校验（升级方向）
