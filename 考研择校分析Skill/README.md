# kaoyan-advisor —— 考研择校分析 Skill

把"考研院校数据分析"项目中的 AI 择校分析能力，封装成一个可被 AI Agent 直接调用的标准 Skill（SKILL.md + 脚本 + 本地数据）。

用户在对话中说出目标院校、专业和预估分数（如"武汉大学金融，预估 370 分"），Agent 识别意图后调用脚本，完成数据匹配 → 分档 → LLM 分析 → 输出校验的全流程，返回分数线预测与冲刺/稳妥/保底三档推荐。

## 目录结构

```
考研择校分析Skill/
├── SKILL.md          # Skill 定义：触发条件、使用步骤、注意事项
├── scripts/
│   └── analyze.py    # 主脚本：数据匹配 + 分档 + LLM 调用 + 输出校验
└── data/
    └── 各院校历年数据采集.csv   # 5780 条录取记录（19 所院校、468 个专业，2023-2026）
```

> 数据从哪来：录取数据由考研帮公开接口采集，**采集代码与 pyecharts 可视化看板**在另一个仓库 [maileji21/maileji.io](https://github.com/maileji21/maileji.io) 的 `02-考研院校数据分析` 目录。本仓库只放 AI 分析与 Skill 封装部分。

## 核心设计

**1. 本地数据 + ±10 分分桶**

不依赖在线接口，直接查本地 5780 条历年录取数据：目标院校专业取历年线，同专业其他学校按"分数线与考生分差"划分冲刺（>考生分+10）/ 稳妥（±10）/ 保底（<-10）三档，同一"学校+专业"去重只保留最近年份，超长列表按行截断防半行。

**2. Prompt 工程约束输出**

要求模型按固定格式输出五段结构（预测线/冲刺/稳妥/保底/建议），预测线必须标注"预测值，非官方公布"；用正则提取各段，解析失败不影响整体返回。

**3. 代码级输出校验兜底（本项目关键点）**

免费小模型（GLM-4-Flash）可能混档（把保底校写进冲刺）、漏档、跨档重复。不信任模型输出：每条推荐里的学校必须在对应分档列表中，否则剔除；某档不足 2 条时从分档列表直接补齐；档位为空时如实输出"该档暂无匹配院校"，不编造。

**4. 环境变量管理密钥**

LLM API Key 从环境变量 `GLM_API` 读取，代码与仓库中不出现任何密钥。

## 使用

```bash
pip install requests
set GLM_API=你的智谱APIKey        # 智谱开放平台 glm-4-flash（免费）
python scripts/analyze.py --school 清华大学 --major 电子信息 --score 345 --html 报告.html
```

stdout 输出 Markdown 分析结果，`--html` 可选生成 HTML 报告。

## 实测示例（清华大学 · 电子信息 · 345 分）

## 已知局限（如实说明）

- 数据为院校**复试基本线**（大类、不区分院系），清华北大等热门院校实际录取分可能显著高于该线，Skill 会在回复中主动提示"复试线≠实际录取分"。
- 数据截至 2026 年，非官方接口可能变动，结论以院校官方公告为准。
